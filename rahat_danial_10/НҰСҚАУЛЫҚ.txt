ҚАЗАҚША ЕСІМДЕРІ БАР ТОЛЫҚ ЖОБА

lab-db/ — PostgreSQL, Sequelize және REST API зертханалық жұмысы.
lab-db/sql/seed.sql — жаңа дерекқорға арналған қазақша есімдер.
lab-db/sql/update_names.sql — БҰРЫННАН БАР дерекқордағы есімдерді UPDATE арқылы өзгерту.
Жаңа база: алдымен schema.sql, кейін seed.sql.
Бар база: тек update_names.sql (id=1..4 оқытушылар, id=1..5 студенттер).

lab10-api/ — №10 Node.js + Express зертханалық жұмысы (№7 Курстар нұсқасы).
Бұл жоба деректерді жадтағы массивте сақтайды, SQL дерекқорын қолданбайды.

Әр жобада npm install, npm test (бар болса), npm start командаларын қолданыңыз.
.env файлына құпия кілттерді енгізіңіз, оны GitHub-қа жарияламаңыз.
